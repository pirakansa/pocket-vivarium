# 小さなプログラムの実行契約

## MEHSのプログラム

回収・探索・通信のいずれかの経験が8回に達すると、未所持の機体は最も経験した分野のルーチンを作る。初期実装は経験に応じたテンプレート合成であり、機体ごとにAIへ問い合わせるものではない。各機体が持つ現在版は1本だけ。

JavaScriptの関数本体を専用インタープリターで実行し、返された行動の優先度を6点上げる。表示用の飾りではなく判断に作用するが、切迫した充電・整備は本体が優先する。追加の資源増殖ボーナスは付かない。通信中に未所持の仲間1機へコピーする。実行回数、採用回数、作者・共有元、ソースを機体ノートで見られる。

## 使い捨ての外界プログラム

[専用Issue #1](https://github.com/pirakansa/pocket-vivarium/issues/1)の本文に、現在版のJSONを一つだけ置く。日替わりのChatGPTタスクが本文を上書きする。コードをGitへコミットしたり、旧版ファイルを作ったりしない。GitHubの編集履歴まで完全消去する保証はない。

Actionsが現在版をrunnerの一時領域へ取得し、新規生成する区間だけに適用する。一時ファイルは必ず削除し、Pages・状態JSON・履歴アーカイブに外界のソースは含めない。記録するのは日付、題名、ハッシュ、結果、適用時刻。通常の状態アーカイブは今までどおり保持する。

日本時間の日付が一致する最初の未生成ステップで1日1回だけ呼ぶ。空配列・拒否も処理済みとして保存する。同日中の差し替え・再実行では再適用しない。プラグインが届く前に生成済みとなった部分は変更せず、その日の残りの未生成部分がなければその日は発生しない。取得失敗・期限切れはイベントなしで日常を継続する。最終処理日だけを状態へ持ち、日数に比例する実行キューは持たない。

先4時間の確定済み記録を保持するため、深夜に差し替えても効果が見えるのは数時間後になる場合がある。スケジュール遅延への既存の余裕を優先する。

## 外界JSON

本文に唯一のjsonコードブロックを含める。

```json
{
  "date": "YYYY-MM-DD",
  "title": "短い出来事の題名",
  "source": "if (ctx.population === 0) return []; return [{kind: \"story\", text: \"遠くの山に大きな影が見えた。\"}];"
}
```

この例は仕様の説明であり、過去の生成プラグインの保管ではない。

入力 `ctx` は `population`, `food`, `parts`, `rain`, `hour`（村の経過時間）, `roll`（0以上1未満の決定的な乱数）。戻り値は最大3件の結果の配列。何も起きない日は `return [];`。

| kind | 追加フィールド | 1日あたりの制限 |
|---|---|---|
| story | なし | 記録のみ |
| supplies | cells, parts | 合計セル0〜6、部品0〜3 |
| interference | damage | 全機体のコンディション低下0〜8。累積寿命は変更しない |
| arrival | なし | 最大1機、稼働機12機未満のときだけ本体が採番・初期化 |
| departure | なし | 最大1機、最後の1機と組み立て担当機は保護 |

全件に `text`（1〜160文字）が必要。全件の検査を通ってから適用する。量はすべて有限の非負数。来訪・旅立ちは条件が合わなければ物語の記録だけになる。来訪機はその後本体の通常の寿命管理を受ける。旅立った機体は台帳にdeparture時刻を残すが、自動帰還の処理を予約しない。

ウイルスや巨大な影などの題材は `story` と軽い `interference` で表現できる。現段階では即死・強制引退・日をまたぐウイルス状態・遠征の自動帰還は追加しない。出来事の結果は残るが、イベント固有の継続処理やコードは残らない。

## 実行するJavaScriptの範囲

使える構文は `if/else`、ブロック、`return`、リテラル、配列、単純キーのオブジェクト、`ctx.key`、括弧、算術・比較・論理演算。文字列はJSON互換のダブルクォート。関数本体として書き、returnの末尾にセミコロンを付ける。コメント、変数宣言、関数呼び出し、ループ、代入、任意のプロパティ参照は非対応。

一般のJavaScript実行環境へ渡すevalやnode:vmは使用しない。ソース4096文字、1024トークン、構文深さ40、実行2048命令に制限したパーサー・インタープリターが対応部分だけを実行する。ホストのprocess、ネットワーク、ファイル、タイマーは提供しない。返せる結果も本体が検査する。JavaScript全仕様との互換を目的にしない。

本体の数値制約、採番、世代・寿命、記録窓、描画、永続化はプラグインから変更できない。過去を再現するときは保存したJSONを読み、古いプログラムを再実行しない。

検証: `node tests/programs.cjs`。既存の全テストも実行する。
