# Pocket Vivarium — こもれびの村

住人の暮らしを眺める、小さな箱庭の試作品です。

## 起動

```sh
python3 -m http.server 8000 --directory dist
```

http://localhost:8000 を開きます。fetchでJSONを取得するため、HTMLの直接起動ではなくHTTPサーバーを利用してください。ビルド・追加依存関係は不要です。

## 現在の構成

- `dist/state.json`：村の時刻・食料・天候・住人・行動・経験・記録。
- `dist/index.html`：JSONを読み取り、村と住人を描画。
- 起動時、画面に戻った時、表示中は60秒ごとにJSONを再取得します。
- ブラウザ内で時刻・欲求・経験・食料を進める処理とlocalStorageへの保存はありません。
- 状態が同じでも、住人は活動場所の周辺を歩いたり立ち止まったりします。描画用の座標は状態JSONと別にメモリー内で管理し、JSONを書き換えません。
- 「動きを一時停止」は見た目の歩行を止めます。世界の状態や定期更新を操作するボタンではありません。
- 時間送り・食料補充・雨・初期化は、更新先のバックエンドが未実装のため画面から外しています。
- 現在は固定サンプルJSONを表示し、定期更新・バックエンド・スケジュールは実装していません。
- JSON取得に失敗した場合、直前の表示を維持してエラーを表示します。初回失敗時は読み込み失敗を案内します。

## 今後の方向性

将来、cron等で1日12回程度シミュレーションを実行し、状態JSONを更新する構想です。フロントエンドはその結果を観察する画面とし、更新の間も暮らしているように描画します。今回その定期実行の仕組みは作っていません。

住人への逐一の命令ではなく、性格・欲求・経験から生まれる行動を見守る体験を目指します。元の試作はルールベースの優先度計算で、生成AIは使用していません。今後のシミュレーションはブラウザの外へ移す予定です。
