# Pocket Vivarium — こもれびの村

性格・欲求・経験から行動を選ぶ3人の住人を眺め、少しだけ介入する箱庭シミュレーションの試作品です。

## 起動

`dist/index.html` をブラウザで開くか、リポジトリ直下で次を実行してください。

```sh
python3 -m http.server 8000 --directory dist
```

ブラウザで http://localhost:8000 を開きます。ビルドや追加依存関係はありません。

## 現在の仕様

- ハル（慎重）、ユイ（仲間思い）、レン（冒険好き）の3人が生活します。
- 空腹・体力・交流欲求・好奇心・性格・採集経験・食料・雨・時刻から、食事・休息・採集・交流・探検の優先度を計算します。
- 最も優先度の高い行動を選び、住人の詳細に理由と上位3行動の点数を表示します。
- 食料補充、雨の切り替え、一時停止、1時間進行、速度変更、初期化を操作できます。
- 通常速度では約3秒で世界の1時間が進みます。
- 状態は各時間の進行と介入時に localStorage の `komorebi-v1` に保存します。同じ端末・ブラウザ・オリジンで再読み込みすると復元します。
- サーバーへの状態保存や端末間同期はありません。閉じている間の時間経過も計算しません。
- 保存対象は村の状態です。選択中の住人、一時停止、速度は再読み込みで初期値になります。
- 保存データを削除した場合、または読み込みに失敗した場合は初期状態になります。

## 方向性

実用上の困りごとを解決する道具ではなく、自分で作った世界を眺めて楽しむための実験です。住人を逐一操作せず、性格と状況から生じる行動の違いや経験の影響を観察します。現在はルールベースで、生成AIや学習モデルは使用していません。

将来ラズパイ等で常時進行させる構想はありますが、現時点ではシミュレーションと描画の両方がブラウザで動きます。
